# HN Reader

A simple, lightweight Hacker News reader that shows articles you're interested in.

## Features

- 📰 Fetches top stories from Hacker News API
- 🎨 Clean, responsive design for mobile and desktop
- ⚡ Fast and lightweight
- 🔗 Direct links to articles and HN discussions

## Live Demo

This project is hosted on GitHub Pages: [View Demo](https://csabag.github.io/project_001/)

## Tech Stack

- Pure HTML, CSS, and JavaScript (no frameworks)
- Hacker News API (https://github.com/HackerNews/API)
- GitHub Pages for hosting

## Getting Started

Simply open `index.html` in your browser, or visit the live demo link above.

## Customization

You can modify the filters in `app.js` to customize which articles are displayed based on your interests.
